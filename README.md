> **Institutional-grade property management and resident experience platform.**

NexusRent is a modern, high-performance web application designed to bridge the gap between property owners and residents in Kenya. Built with precision and security in mind, it provides elite tools for landlord management and a frictionless living experience for tenants.

---

## 🚀 Key Features

### 🏢 For Landlords & Property Managers
- **Real-time Analytics**: Institutional-grade dashboards for yield analysis, collection rates, and occupancy trends.
- **Automated Collection**: Integrated M-Pesa rent collection with automated reconciliation and reporting.
- **Tenant Screening**: Professional screening tools to ensure high-quality resident placement.
- **Maintenance Management**: Centralized tracking for maintenance SLAs and work orders.

### 🏠 For Tenants & Residents
- **Frictionless Payments**: Pay rent directly via M-Pesa with instant digital receipts.
- **Service Requests**: Raise maintenance tickets and track progress in real-time.
- **Digital Lease Storage**: Secure, anytime access to lease agreements and important documents.
- **Enhanced Communication**: Direct, transparent communication channel with property management.

---

## 🛠 Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **UI Components**: Custom-built premium components with [Shadcn UI](https://ui.shadcn.com/)

## 📂 Project Structure

```text
src/
├── app/              # Next.js App Router (Auth, Landlord, Tenant portals)
├── components/       # Reusable UI components (Navbar, Logo, Loader, etc.)
├── context/          # Global state management (AuthContext)
├── data/             # Mock data for prototyping and development
├── hooks/            # Custom React hooks
├── lib/              # Core library utilities (shadcn/ui, etc.)
└── utils/            # Helper functions and formatting utilities
```

## 🏁 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/hamisigad71/rentupdated12.git
   cd rentupdated12-main
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Access the application**:
   Open [http://localhost:3000](http://localhost:3000) in your browser.
